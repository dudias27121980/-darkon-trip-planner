# דרכון · מתכנן טיולים

כותבים מדינה, מקבלים את כל המידע שצריך לפני הטיסה, עונים על שאלון קצר ומקבלים מסלול והמלצות שמותאמים אישית.

**המערכת היא קובץ HTML אחד.** פותחים את `index.html` בדפדפן, בלי התקנה ובלי שרת.

## מה יש בפנים

1. **כרטיס מדינה:** שעה מקומית חיה והפרש מישראל, מספרי חירום, כניסה עם דרכון ישראלי, שפה, מטבע, תקעים, צד נהיגה, זמן טיסה מתל אביב, עונה מומלצת וטיפים במסעדות. דגל המדינה מתנופף ברקע.
2. **שאלון:** מי נוסע, כמה לילות, קצב, תחומי עניין ותקציב.
3. **כשרות וחב״ד:** מפה אינטראקטיבית ורשימה של בתי חב״ד ומסעדות כשרות בכל יעד: סוג (בשרי, חלבי או צמחוני), כתובת וקישור ניווט.
4. **המלצות:** חלוקת הלילות לבסיסי לינה, מקומות עם ציון התאמה והסבר, לינה, אוכל (כולל כשרות), התניידות וטיפים. לכל מקום יש קישור למפה ולסרטונים.

## תמונות

תמונות הרקע של כל מדינה (כ-35 אתרים מפורסמים, כמו פסל החירות, ואט ארון ומגדל אייפל) נטענות מוויקישיתוף (Wikimedia Commons) ברישיונות חופשיים. על כל תמונה מופיע קרדיט שמקשר לדף הקובץ, ושם מפורטים שם הצלם והרישיון. אם התמונות לא נטענות, ברקע מופיע הדגל המתנופף.

## יעדים

איטליה, ספרד, יוון, צרפת, פורטוגל, בריטניה, ארצות הברית, יפן, תאילנד, גאורגיה.
מדינה שאין עליה מידע מאומת לא מקבלת נתונים מומצאים.

## חשוב

דרישות כניסה, מחירים ושעות פתיחה משתנים. לפני נסיעה בודקים באתר משרד החוץ ובאתרים הרשמיים של המדינה.
